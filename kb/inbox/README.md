# inbox — staging only

Nothing in this folder is ingested.

Drop supporting .md files here. Each one gets triaged (KNOWLEDGE.md section 2) into:

  ontology/   metric, screen, widget or action definitions  (structured, never embedded)
  catalog/    things Genie can do                            (structured, never embedded)
  kb/<tier>/  prose: policy, SOP, FAQ, release notes         (embedded, needs frontmatter)
  excluded    internal engineering, stale, draft, or live client numbers

Default is deny: a document enters the corpus because someone tagged it
audience: and status: published — not because it was in the folder.
